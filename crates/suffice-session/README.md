# Read-only session core (experimental)

This crate implements a candidate discovery and Pi-style projection boundary. It is not wired into the desktop application and does not migrate, rewrite, or create sessions. The stdin/stdout JSON executable is a differential-test and future-host interface, not a user-facing CLI. Operations are `journal` (source), `discover` (root), and `project` (entries, optional leaf); responses contain `ok` and `result` or `error`. Projected entries use `sourceIndex` to preserve journal provenance. Explicit null leaf means empty path; omitted leaf means last entry. Cyclic parent chains return an error, whereas Pi 1.5.2 can hang.

Run `cargo build --offline --manifest-path crates/suffice-session/Cargo.toml`, then with Node 24 `node --test crates/suffice-session/tests/differential.test.mjs`. Tests import the installed Pi 1.5.2 and use only temporary fixtures. Set `SUFFICE_PI_ORACLE_ROOT` to a checkout with the pinned Pi installation when the crate checkout has no local `node_modules`. Opaque JSON object insertion order is preserved through the Rust wire format; JavaScript additionally enumerates integer-index keys in numeric order after parsing, so the raw Rust wire text is not necessarily identical to `JSON.stringify` for such keys. The fixture file hashes are compared before and after discovery. Rust checks: `cargo fmt --manifest-path crates/suffice-session/Cargo.toml -- --check`, `cargo clippy --offline --manifest-path crates/suffice-session/Cargo.toml --all-targets -- -D warnings`, `cargo build --release --offline --manifest-path crates/suffice-session/Cargo.toml`.

This is partial and must not replace production browsing without broader differential tests and integration review. Known gaps include JS Date parsing beyond tested RFC3339, date-only strings and numeric/null values; JS coercion, numeric and undefined edge cases; malformed primitive entries and messages; locale-dependent filename ordering, symlink and discovery error behavior; case and path semantics; and invalid Unicode. Root discovery orders equal activity times by file mtime and descending basename; only ASCII tie fixtures have been compared with Pi. Projection rejects null entries/messages with an error rather than reproducing Pi exception text. The executable reads entire files; its memory behavior has not been evaluated on large sessions. Desktop presentation, session metadata, usage, confinement, caching, and model resolution are outside this crate. Fixtures are synthetic, not full end-to-end UI or old-session migration parity evidence.
