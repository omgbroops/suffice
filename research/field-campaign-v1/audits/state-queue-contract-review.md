2. **q03's active regression asks for broader cancellation than the supplied public example.** Its two functions return promises that never settle and never handle the signal; the test requires the already-running function's `queue.add()` promise to reject with `AbortError` and pending to become zero. The issue's example uses `fetch(...,{signal})`, which cooperatively rejects. The original README explicitly says that an already-running operation must handle its signal itself (`readme.md:144`), and describes `AbortError` as the pre-run abort error (`readme.md:383`). A narrow fix that always releases queue accounting for an aborted waiting task, while preserving that documented cooperative-running policy, could fix the public reproduction yet fail this grader. The test is an actual upstream added test, and the reference implements abort racing, but upstream provenance alone does not establish that the original requirements require this stronger behavior. Treat this as a substantive contract concern, not proof of an incorrect actor.
3. **q02 has an inactive added cleanup check.** The overlay adds five tests, but its name pattern selects the four `resolves when` / `resolves multiple` cases. `.onSizeLessThan() removes its listeners once resolved` does not match and is not graded. Native tests run before this overlay, so they do not recover that new check. This weakens coverage; it does not make the four executed expectations unfair.
4. **BNT counts need a file-level caveat.** s02/s03 report 50/53 passing Node test entries through the original Better Node Test runner, across all 14 original `*.test.js`/`*.test.ts` files. Six entries are file-level passes rather than separately named inner tests: atom, computed, deep-map, deep-map production, map, and map production. Those six files contain 83/111 statically visible top-level `test(` declarations respectively. Their successful file entries and incidental body output demonstrate loading/execution, but the saved reporter output does not establish an individual result for every internal declaration or assertion. Do not call 50/53 the complete original assertion count, or claim all inner assertions were independently enumerated. No full coverage, lint, size, or declaration-test CI run is claimed for state tasks.
5. **Minor presentation/provenance differences are disclosed.** s01/s02 `publicBody` differs from saved GitHub JSON only by CRLF-to-LF normalization. s03 additionally has one em dash encoded as mojibake in a code comment; the requirement and executable reproduction are unchanged. s01/s02 `.gitignore` adds a redundant `node_modules/` entry. These are not private tests or solution files, but raw archive identity should not be claimed for those bases without these exceptions.
