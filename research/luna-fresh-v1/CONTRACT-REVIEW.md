# Contract and design review before inference

Six fresh-to-actor resolved GitHub issues; three p-map snapshots, one each p-timeout, p-retry, fastq. This is six tasks across four repositories, not six repository-independent samples. Scope is asynchronous library engineering, not a general long-horizon benchmark.

Independent provenance means original upstream reporters and upstream regression tests, independent of each coding actor. The parent operator reviewed assertion-to-requirement mappings and controls; there was no second human or review-model call. No subagents were spawned.

Excluded: p-timeout42's original reference introduces p-timeout43's handled-rejection bug. Its rejected fixture remains preserved. p-timeout47's open-ended cancellation question was not admitted. fastq88's unrelated undefined-drain assignment test was excluded. p-map94's exact speculative mapper counts were generalized to the observed count at close; no extra work may start after close. The unrelated exact in-flight count assertion was removed.

p-map95 and p-retry97 contain solution suggestions in their ORIGINAL bodies. They remain visible and are marked hinted; source localization is easier than a blind issue. All issue bodies are supplied verbatim; later comments and fixing patches remain inaccessible. Private tests run only after the coding worker exits and never become repair feedback.

The public AVA cache:false config is an environment adaptation, identically supplied to both arms and grader. Initial cache-write failures and the ineffective CLI flag attempt are preserved with zero inference calls. Behavioral/type dependencies are installed; lint orchestration is unavailable in the bounded environment. Commands and dependency locks are frozen with task receipts.

A is the exact previous Luna-xhigh runtime/prompt. B adds ONE deterministic original-public regression gate after the first submission, with original protected test bytes restored in a separate copy and one repair continuation on failure. No self-authored probe, extra planner, hidden-test feedback, requirement ledger, or new prompt text. All repair calls consume the same cumulative task budget.

Sequence: all six A first, then six B in reverse task order, as requested. This cannot remove an arm-by-time/cache confound. One run per task per arm is exploratory; no significance or universal superiority claim.

Before fresh outcome labels, freeze the handoff signal: original public checks fail OR worker not operationally completed OR no production patch. It uses no hidden acceptance, model judge, or extra inference. Study precision, recall, false negatives and incremental Sol cost; do not automatically deploy routing. A Sol continuation, if justified by these PUBLIC signals, receives the current production patch and public diagnostics only; original Luna cost remains part of the same task allowance.

$0.15 API-equivalent total inference cap per task/arm (not a target), six pairs <=$1.80 planned cap. Optional signal-triggered Sol cost is bounded by remaining allowance on the corresponding Luna task, not an extra $0.15. All engineering inference and subscription cash spending remain separate.
