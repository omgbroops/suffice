## Preflight v1 amendment, before any paid actor outcome

Sonion reference controls exposed a grader representation bug in the b10/b11 `onlyFirst` assertions: non-global JavaScript `String.match()` returns a `RegExpMatchArray` with `index`, `input`, and `groups` metadata, so deep equality against a plain array rejected a correct match. Those two assertions now normalize the match with `Array.from(match ?? [])` before comparing matched text. The expected behavioral contract and examples are unchanged; missing or incorrect matches still fail. This is a pre-inference grader correction based exclusively on original/reference controls, with no model outcome feedback.

Native AVA controls also encountered writes to a cache under read-only `node_modules`. The root preparer owns the global command amendment to disable AVA caching with `--no-cache`; this agent did not modify cohort native commands. b12's independent acceptance grader already passed the reference control and is unchanged.
