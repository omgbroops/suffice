# Suffice v10: Pi tools with the bounded controller

V10 restores the existing Pi agent runtime and tool stack, then adds v9's independent public-spec tests, arbitration, checkpoint selection, bounded repair and selective takeover. V9 remains a separate historical native-CLI experiment. No v10 command launches `codex exec`.

Workers use the pinned `@earendil-works/pi-coding-agent` and `pi-ai` 1.2.0 packages. All four benchmark arms get the same Pi codemode and AST tools: `symbols`, `symbol_read` and `symbol_references`. Navigation reindexes after edits, supports JavaScript and stripped TypeScript, and provides a plain read/search fallback when parsing fails. References are syntactic candidates, not resolved call graphs.

File listing, reads, search and the navigation implementation reuse the original Suffice modules. Exact edits/writes now support workspace files beyond `src/`, with original tests protected. The test tool runs caller-declared public argv checks; local `exec` supports other development commands. Compact output and full-observation recovery reuse `observationTools`. Compact output is independently selectable with `compactResponses: true`, and defaults to false, following the earlier navigation-only finding.

Luna (`gpt-6-luna`, high effort) implements and may repair once. Sol (`gpt-6.1-sol`, low effort) writes independent tests from the public task and original interfaces. A separate Sol completion arbitrates generated failures against exact public requirements. Sol high takes over only for remaining verified failures. Every checkpoint is rescored against the current suite; public regressions dominate generated gains. Ambiguous assertions stay unverified. Existing tests and supported runner settings are preserved. Project-specific mixed configuration needs explicit `protectedPaths`.

Reviewers use direct Pi completions with `tools: []`, no agent session, no codemode and no worker filesystem/history. The controller validates their JSON and rejects any returned tool call. This removes the native CLI's tool-schema restriction problem from the reviewer path.

## Use

Pi uses its existing separate subscription authentication directory, `.suffice/pi/`. Desktop login is not copied. The user completes the browser sign-in; credentials never appear in reports. There is no API-key or model fallback.

```powershell
npm run login
npm run v10:preflight
# JSON request on stdin, same fields as v9, with strategy "v10":
Get-Content -Raw C:/work/request.json | node scripts/v10-run.mjs
```

See the [v9 request format](V9.md#run). V10 uses `.suffice-v10-checks` as its reserved generated-test directory. A fresh task Git root and external receipt directory are required. Regular-file snapshots still have the shared 5,000-file / 64 MB limit. This is a bounded experimental runner, not unrestricted general repository support. Read/list tools retain the original public-file and per-file size limits. Local commands can access the host; this is not an OS sandbox.

## Budget and evidence

Each request gets a conservative reservation before dispatch: serialized context bytes plus 8,192 tokens of overhead, the most expensive pinned input/cache rate, and at most 6,000 output tokens. Reservations that exceed the remaining stage allowance are refused. The pilot refuses conservative input estimates above 200,000 tokens, below the long-context price boundary. Pi's actual reported usage settles the estimate; unknown receipts retain their known cost floor and stop the campaign. Reservations are accounting controls based on the pinned pricing/token assumptions, not provider billing enforcement.

The worker also checks allowance at tool and provider boundaries, with no automatic provider/agent retries. Actual Pi loop tests verify that a continuation cannot dispatch a second paid request after a stop. Deadlines cancel development processes. All stages share the controller's total allowance, and any observed overshoot remains recorded and ineligible. Usage costs are API-equivalent estimates, not subscription invoices.

Receipts contain model identity, effort, usage, request reservations, costs, selected source hashes, checks and tool events. Navigation and observation-recovery events show which tools were actually used. A registered capability is not evidence that a model used it. The selected source and checks are authoritative; the final model message can describe a discarded checkpoint.

## Benchmark

Compare `luna`, `sol`, `ladder` and `v10` on the same Pi tools, public task/checks, efforts, time/cost allowances and isolated source copies. This comparison measures the controller bundle; AST and compact-output effects require separate ablations. Historical Pi/Claude/native-CLI results are not pooled.

```powershell
node scripts/v10-pilot.mjs C:/work/new-v10-pilot --real
node scripts/v10-bench.mjs plan C:/work/new-v10-pilot/public-manifest.json C:/work/new-v10-pilot/plan
node scripts/v10-bench.mjs run C:/work/new-v10-pilot/plan
# After execution closes, introduce an external evaluator configuration:
node scripts/v10-bench.mjs grade C:/work/new-v10-pilot/plan C:/work/private-evaluators.json
node scripts/v10-report.mjs C:/work/new-v10-pilot/plan
```

The pilot schedules 16 attempts: two authored development tasks plus two historical node-semver issue replays at `efa4be6096c1f9b77d9d27d6132f6220c43b4e31`. Both upstream bug reproductions fail on the original code while the accompanying ordinary-regression checks pass. Source archive URL/hash and task snapshots are recorded. These tasks are previously studied development material, not unseen efficacy evidence. No private evaluator files are introduced before actors finish. Author deferred graders using the original public contract/reference behavior without inspecting actor outputs.

The new campaign allowance is $9, reserving $1 of the user's earlier $10 allowance for the unresolved rejected v9 CLI attempt. This does not turn that prior unknown cost into a measured charge. Each attempt has $0.50 and 300 seconds. The plan freezes Pi package versions, Node, models/efforts, source/runtime hashes and a seeded interleaved schedule. It refuses execution when Pi subscription sign-in is missing. Unknown usage stops further actors. The shared [deferred-grading protocol](V9-BENCHMARK.md) and its local-isolation limitations still apply.
