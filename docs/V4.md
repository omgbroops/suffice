## What v4 changes

Implemented (`src/v4-escalation.mjs`, `tests/v4-escalation.test.mjs`):
- Cheap model `claude-haiku-5-5` runs up to K=3 rounds. Round 1 gets the task prompt. Later rounds get only `V4_RETRY_MESSAGE` (copied from decomp-v2 `bench/polyglot.py:19`).
- The attempt callback returns `{ pass, costUsd }`. No test text crosses this boundary.
- Escalation runs once on `claude-opus-5-5` only after K failed rounds, and only if spent + strong estimate fits the budget.
- Missing budget throws `BUDGET_REQUIRED`. Unknown cost throws `COST_UNKNOWN`.
- Each row records `firstAttemptPass`, `roundsUsed`, `roundCostsUsd`, `escalated`, `finalPass`, plus costs and `escalationSkipped`.

Wired:
- Thin profile: Read/Edit/Write/Bash only, via the Claude CLI (`src/v4-claude.mjs`).
- Hidden-test verdict: the acceptance test runs outside the agent workspace and returns pass/fail only.
- Runner (`src/v4-runner.mjs`): always writes exactly one row per run, including on crash, timeout, or unknown cost.
- CLI (`scripts/v4-run.mjs`): `--budget-usd` is required; missing or non-positive values exit 2 with no row written.

shortcut: the hidden test is a file path Bash can read, so this is a convention, not a sandbox. Upgrade to an OS-level read block before trusting results.

## Live pilot (not run)

Not run. Do not run without approval. The command is:

    nice -n 19 node scripts/v4-run.mjs --budget-usd=<USD per run> --tasks=retry-idempotency,cursor-pagination,tenant-cache,window-scheduler

Worst-case cost is a hard cap, not the rate-card estimate. Each run stops at `--budget-usd`, and each attempt gets the remaining budget as `--max-budget-usd`. Total worst case = tasks × repeats × budget-usd. With the 4 tasks above and `--repeats=1`, that is 4 × budget-usd. Use `--repeats=2` and it becomes 8 × budget-usd.

Rate card (decomp-v2 `pricing.py`, unreconciled with vendor pricing):
- Opus: $4 in / $20 out per M tokens.
- Haiku: $0.10 in / $0.50 out per M tokens; $0.50 / $2.50 above 100k context.

Estimate from the module (not a cap): about $0.0043 per Haiku round and $0.0705 per Opus attempt, so about $0.0834 per task. This may understate Opus cost at large contexts.
