## What v4 changes

Implemented (`src/v4-escalation.mjs`, `tests/v4-escalation.test.mjs`):
- Cheap model `claude-haiku-5-5` runs up to K=3 rounds. Round 1 gets the task prompt. Later rounds get only `V4_RETRY_MESSAGE` (copied from decomp-v2 `bench/polyglot.py:19`).
- The attempt callback returns `{ pass, costUsd }`. No test text crosses this boundary.
- Escalation runs once on `claude-opus-5-5` only after K failed rounds, and only if spent + strong estimate fits the budget.
- Missing budget throws `BUDGET_REQUIRED`. Unknown cost throws `COST_UNKNOWN`.
- Each row records `firstAttemptPass`, `roundsUsed`, `roundCostsUsd`, `escalated`, `finalPass`, plus costs and `escalationSkipped`.

Not implemented (remaining):
- Thin profile (Read/Edit/Write/Bash, tiny system prompt) in the pi runtime.
- Hidden-test verifier wiring. The oracle test runner and verdict plumbing do not exist yet.
- A `v4` entry in the `variants` table and a CLI that passes the budget flag.
