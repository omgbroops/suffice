## 3. Every results file as a row

Column notes:
- **acc %** = pass / rows. Rows can exceed unique tasks when a file holds repeats or retries.
- **first-try pass** = `firstAttemptPass` field; `—` when the file lacks the field.
- **self pass, hidden fail** = the agent's own gate said pass and the hidden grader said fail. **self fail, hidden pass** = the reverse.
- **escalated / esc skipped / fix rounds / rescued** come from row fields of the same names; `—` = field absent.
- **wall min** = max(t) − min(t) over the ledger file `X.jsonl.ledger.jsonl`. Merged files have no ledger.
- **calls / turns / tokens / models** come from `calls[]` (or `selfTests[].model` for older rows). Tokens = input + output + cache read + cache write.
- **failed tasks: recorded reason** = the task id, then a label built only from `status`, `error`, `selfFinalPass`, `fixRounds` (see `reason()` in the script). It is a field readout, not a diagnosis.
