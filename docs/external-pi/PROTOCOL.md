# Frozen Suffice versus native stock Pi pilot

Question: how does the existing Suffice benchmark baseline compare with real stock Pi on independently graded coding repairs at the same per-attempt inference allowance? No optimization mechanisms are added or tested.

Suffice is the byte-unchanged `src/benchmark-agent.mjs` from a2745c6: nine core/navigation tools through codemode, its existing short system prompt and existing settings. The common authentication bridge uses the canonical file-backed SDK store, fixing the previously documented stale-refresh issue without changing tools or model behavior.

Stock Pi is the actual installed 1.2.0 bundled CLI in JSON mode, with its stock system prompt, read/bash/edit/write defaults and built-in extensions. No restricted SDK substitute, tool allowlist, prompt replacement, codemode-only override, retry reduction or disabling of stock compaction/cache warming. A read-only extension records requests, finalized replies and tools; it also enforces the common benchmark stopping conditions. Offline startup freezes catalog discovery, not inference or native tools. Ambient API-key variables are removed to keep the authorized subscription route.

Eight attempts, one per arm/task, serial and alternating order:

| Pair | Tasks and scope | Allocation | Order |
| --- | --- | --- | --- |
| 1 | fastq pause/resume and worker accounting; stateful single component | Previously exposed adapter validation; excluded from evaluation conclusions | Suffice, Pi |
| 2 | Bottleneck priority queue plus weighted datastore reservation/release and public scheduler integration | Previously exposed exploratory comparison | Pi, Suffice |
| 3 | Emittery asynchronous iterator lifecycle, return/stop/clear and pending deliveries | Previously actor-unused reserve fixture | Suffice, Pi |
| 4 | tinyqueue heap state through mixed operations and comparator contracts | Previously actor-unused reserve efficiency control | Pi, Suffice |

These are disclosed injected-defect tasks on complete pinned real repositories. Contracts, reference solutions, assertion mappings and independent earlier reviews are reused unchanged. Scope is declared before inference. No duration, edit-count, turn-count or context inflation; no long-horizon or mechanism-activation claim. Reserve means no prior repair attempts, not that evaluators have never seen the code or that public upstream source is absent from training. No new real-world issue dataset is claimed.

Gates before evaluation: native CLI startup resolves exact model/provider/pricing, actual default tool inventory and stock prompt; local native read/write/edit/bash probes work; defective originals fail justified private assertions, references pass, and visible regression samples pass; both adapter-validation attempts have complete event-based costs and correct actual Sol-low identity. Adapter failures are retained and never count as coding failures. No replacement attempt or post-score harness edits.

Both use GPT-6.1 Sol low, the same provider/pricing, Windows/Node/PATH, initial actor bytes, public task text and local actor-only Git base. Working directories use opaque IDs. Native system prompts and tool capabilities intentionally differ as product behavior; byte equality across products is not required. Save and explain full instruction differences, check per-task user equality and within-arm instruction stability after replacing only exact cwd fields. No automatic passing of unexpected differences.

Private/reference data remains outside actor folders. Native stock shell tools retain ordinary host permissions; this is not OS-contained evaluation. Both receive a workspace-only/no-network task policy. Review all calls for evaluator/reference access; invalidate contaminated attempts. Stock may create scratch tests while the existing Suffice interface cannot; do not remove that native advantage. Only existing allowed production edits are submitted, provided fixture files remain immutable, and acceptance runs on clean reconstructed workspaces rather than agent-edited tests. Scratch files outside src are archived but not submitted.

Per attempt: $0.20 API-equivalent post-response threshold, 24 assistant replies, 120 tool calls, 240 seconds. Campaign: eight attempts, $2 known-cost admission target, stop new admissions on one unknown full cost, 128 MiB campaign artifacts and 1 GiB minimum free disk. Limits can overshoot by one response and are not billing guarantees. Count failed attempts/retries and preserve unknown totals. Any unmatched auxiliary request remains unknown rather than free. No claim of complete cost if stock background inference cannot be reconciled.

Primary measures: acceptance, accepted within budget, all-attempt cost per accepted task and cost per budget-eligible success. Separate fresh/cache/output costs, turns, calls, latency, coding failures and operational failures. Report adapter-validation, exposed-pilot and actor-unused-reserve cohorts separately; show all-attempt totals as additional accounting. No success-only pair selection. No statistical superiority claim from one repetition.

Stop after this pilot and deliver the observed comparison, task discrimination and smallest justified decision. Do not enable a new mechanism, expand to another optimization campaign or silently repurpose the reserve after seeing outcomes. Native Pi documentation/provenance: https://github.com/earendil-works/pi and installed pinned CLI/docs.
