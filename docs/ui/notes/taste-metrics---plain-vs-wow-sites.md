# Taste metrics - plain vs wow sites

A taste metrics tool measured 16 baseline sites. Plain sites had a median of 5 distinct colors, 4 font sizes, 0.7 KB CSS and 43 DOM nodes. Wow sites had 8 colors, 10 font sizes, 9.1 KB CSS and 81 DOM nodes. Restraint metrics could not tell plain-but-lazy from good, and class counts mostly detected Tailwind rather than slop.

The owner wants monochrome liquid glass, no vibecoded look, and screenshot-verified output (2026-10-14). Unverified: from extraction. See [[Spinner word list - rejected terms]].
