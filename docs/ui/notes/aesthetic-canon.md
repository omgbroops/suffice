## 3. RULES

1. Look at real references first; a ban list only moves the collapse. [n=2: Mode collapse 2026-10-28, "UI clone test" picks 2026-11-07]
2. Replicate a liked ref faithfully, then adapt across several into an own look; never ship the plain clone. [n=1: 2026-11-09 "you just cloned it"]
3. Subtract content, not character: cut copy, labels, hints, meta lines; keep colour, layout and personality. [n=2: 2026-10-22 labels, 2026-10-12 Rasoi]
4. Too minimalist is as bad as slop; want a few BIG contrasty areas, not many tiny bits. [n=1: 2026-11-07 ERP]
5. Motion must be functional, subtle, smooth; never flickery or competing with the content. [n=2: 2026-11-06, 11-09 "fainter not fewer"]
6. Fainter means lower ink at the same structure; never add motion on a calmer note. [n=1: 2026-11-09]
7. Backgrounds are sparse, faint, still distinguishable, and never take focus from the main object. [n=1: taste picks ember/lanterns]
8. For app UI the UI is the hero; art is faint and optional. Artwork-as-hero only for art-demo pages. [n=1: 2026-11-12 correction]
9. Tinted near-black or warm paper per product, hairlines at alpha 0.07-0.12, 3-step text ladder. [n=1: Harness UI study]
10. Small nested radii; pills only on primary CTAs; no big rounded slabs. [n=2: Harness study; picks capsule/float NO]
11. Type: modest sizes, tight tracking, one mono beside the sans; large sidebar or run text is a NO. [n=2: picks sidebar-index, run-sentence]
12. Dense reference-like layouts (Linear) over huge diffs or cards. [n=1: pick run-diff]
13. Exact and clean first; wear/dirt is a last, optional layer. [n=1: 2026-11-08]
14. Real or scanned assets for realism; procedural rectangles fail. [n=1: 2026-11-06]
15. Work one component at a time with intention + refs, not a forced full build. [n=1: 2026-11-06 guided build]
16. Critic scores and benchmarks are not the bar; his eye and blind picks are. [n=2: 2026-10-20, 11-09]
17. Prove UI by a visible click script plus a screenshot you looked at, off his screen. [n=1: 2026-11-06/07]
18. Keep an old design he likes; patch defects only. Dated beats modernist. [n=1: 2026-10-11/12]
19. Do not try to be clever outside the host: add nothing the host does not already have (see section 4). [n=1: 2026-11-12 tonight]
20. On "it got worse" go back to the oldest version he liked and restart, do not keep layering. [n=2: 2026-10-16, 2026-11-12]
