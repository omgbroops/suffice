Avoid unnecessary secondary labels and descriptions in UIs; let the layout do the explaining (user, 2026-10-22, on /uil).

**Why:** clutter hurt readability on the /uil quiz page (meta line, "Shared code · questions" header, keyboard hint row).
**How to apply:** no meta/subtitle lines, section headers, or hint rows unless essential; scores/status appear only once meaningful. Pairs with [[feedback-ui-taste]]; still keep trust lines short per [[feedback-text-diet-shorten-not-delete]].
