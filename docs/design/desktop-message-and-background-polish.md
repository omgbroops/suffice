# Desktop message, search and background polish

Message actions float six pixels below their anchor, using the composer material. A user toolbar sits to the right with sent time and Copy; a completed agent toolbar sits to the left with recorded whole-run duration, model/provider, effort and full-response Copy. It reserves no transcript space. Attachment thumbnails form a wrapping grid below user messages and open the existing image viewer. Images retain filenames after reopening. File content is not duplicated solely for previews.

Appearance keeps its existing Background picker. Custom reveals Image and Effect rows in the same raised card. Choose/Replace use the native file chooser; Adjust opens a compact preview with drag framing, zoom, Cancel and Done. Effects are None, Dither, ASCII, Halftone and Scanlines. No image is uploaded. The standard chat/settings background controls still determine where it appears. Both horizon presets use pale blue and warm light-mode artwork while preserving their dark versions.

Spotlight keeps its floating, transparent backdrop. Thread rows contain project mark, title, project/branch, colored chat changes, provider history, status and age on one line. Long fields truncate. Search controls retain the established keyboard behavior.

LaTeX supports inline dollar/parenthesis delimiters, display dollar/bracket delimiters and common equation/alignment environments. Safe local typesetting follows Markdown sanitation; code is unchanged. Small code-block copy buttons appear on hover or keyboard focus and stay available on touch pointers.

Validation uses real offline Electron fixtures: whole-turn copy and timing, no layout growth, attachment reload/preview, both-theme material equality, all wallpaper effects, crop Cancel/Done and reload, one-line search metadata, math/code/currency isolation and code copy. Exact elapsed duration is only available for newly recorded turns. Legacy attachment filenames are recovered when their original structured references exist; otherwise saved images receive generic names.
