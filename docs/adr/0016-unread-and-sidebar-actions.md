# Unread completion and reversible sidebar organization

Use the user's accent for completed unread dots. Track completion against whether the chat was actually visible and focused, not merely the last selected chat. Store organization in native-backed per-chat view state, keeping read receipts and title overrides separate from engine history. Archive is reversible and hides chats from ordinary filters, while an Archived filter exposes restoration. Only implement context actions supported by current product contracts.
