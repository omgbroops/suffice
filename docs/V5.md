The v5 arm runs the v4 self gate on a ladder of Haiku x2, then one Sonnet `claude-sonnet-5-5` rung (Opus only with `--v5-top=opus`; $0.05 estimate). Escalation is `v5Decision` in `src/v4-escalation.mjs`: escalate only on a patch that does not apply or lands outside cwd, a failed SELFTEST, or an empty patch after its one retry; a patch that does not apply or lands outside cwd, or a failed SELFTEST; `SELFTEST: none` is accepted. Before the Haiku attempt, `src/v5-bundle.mjs` calls the v5 localizer (`src/v5-index.mjs`) on the prepared workspace with the issue text, takes the top 5 files, and puts their ranked list and a `snippet` excerpt per file into the prompt, capped at about 1500 estimated tokens (4 chars per token; the last excerpt is clipped). The model is told to edit those files first and not to search. Gold files are never put into the prompt; `scripts/v4-bench.mjs` only compares them with the bundled files afterwards and writes `localizedFiles`, `bundleTokens` and `goldInBundle` into the row (`goldInBundle` is null when the manifest has no `goldFiles`).

The claude call is leaner for v5 only. `armTiers('v5')` sets `lean: true` and fixes the tools to Read, Edit, Write, Bash; `makeClaudeAdapter({ lean })` then adds `--max-turns 12` and swaps in `V5_SYSTEM_PROMPT` (edit listed files first, read only with line ranges, never print whole files, write a failing test first when feasible, end with `SELFTEST:`). The v4 invocation is unchanged. Shortcut: the token count is an estimate, and the bundle is not checked against the real model's context window. Verified only with the fake-claude stub; no live model run has been made for v5.
