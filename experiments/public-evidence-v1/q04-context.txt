Public behavioral reproduction: q04

Expected behavior: An atom imported from source-a and a computed imported from source-b retain the public reactive behavior: after count.set(2), doubled.get() is 4 and the subscription receives [2, 4].

Source references:
- https://github.com/nanostores/nanostores/issues/371 — Original issue describes separately bundled modules, foreign core stores, and computed values that never update.
- https://github.com/nanostores/nanostores/blob/42225493c37ba9579dc99d909cf63ae433784ea3/README.md#L176-L193 — subscribe receives changes and immediately receives the initial value.
- https://github.com/nanostores/nanostores/blob/42225493c37ba9579dc99d909cf63ae433784ea3/README.md#L306-L338 — computed derives from store values and updates each time dependencies update.
- https://github.com/nanostores/nanostores/blob/42225493c37ba9579dc99d909cf63ae433784ea3/index.js#L1-L3 — Public atom and computed exports.

Executable code (`node reproduce.mjs`, complete clean source copies beside it):
```js
import assert from 'node:assert/strict';
import * as core from './source-a/index.js';
import * as ui from './source-b/index.js';
const count = core.atom(1);
const doubled = ui.computed(count, value => value * 2);
const observed = [];
const unsubscribe = doubled.subscribe(value => observed.push(value));
const before = doubled.get();
count.set(2);
const after = doubled.get();
console.log(JSON.stringify({source: count.get(), before, after, observed}));
unsubscribe();
assert.equal(after, 4, 'computed value should follow the foreign atom update');
assert.deepEqual(observed, [2, 4], 'subscriber should receive initial and changed values');
```
