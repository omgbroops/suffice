# Nemotron same-chunk retrieval, offline v1

Requests use only nvidia/nemotron-3-embed-1b:free. Catalog zero prices and initial response are retained. Initial exact returned-ID validation rejected HTTP 200 because Nvidia serves the route as private/openrouter/nvidia/nemotron-3-embed-1b. This separately frozen protocol permits that observed alias; no fallback or retries. Response cost must be explicitly zero, unknown cost stops indexing.

Six fresh upstream tasks span minimatch, path-to-regexp and marked, fresh relative to prior Suffice retrieval cohorts, not guaranteed training holdouts. Five queries are researcher problem-only paraphrases of public PR descriptions excluding solution sections; one uses an original public issue. Public PR source patches supply held production-region labels. The query author saw PR prose, so these are not blind independent-label annotations. Labels stay outside ranking/embedding. Coverage includes full old-side diff hunk context, a proxy, not proof of necessary or sufficient context.

All arms rank identical nonoverlapping 60-line pinned production-source chunks with identical headers, packing, skip-oversize rule and 2048/4096 estimated-unit ceilings. ceil(UTF-8 bytes/3) is not an actual tokenizer. Compare lexical BM25, syntax name matching, lexical-syntax reciprocal rank fusion, semantic cosine and equal fusion of lexical-syntax and semantic. Exact source remains recoverable by revision/path/range. Automated rankers are not interactive navigation policies.

Freeze queries, held labels, source bytes, policy, runner and provider before scoring. Cache immutable vectors by public input SHA. Embed only frozen public problem prose or source chunks, never labels or private harness code. Batch 32; at most 120 embedding HTTP calls including probe; zero retries. Stop semantic work on first provider failure; retain all vectors/receipts, mark missing outcomes unavailable. No paid substitute. Check 1 GiB disk floor/100 MiB new artifacts before requests.

Index/query latency, tokens, known cost and unknowns are separate. Cold total includes indexing; amortization does not imply free indexing. Engineering inference/source acquisition excluded from benchmark inference cost. No total-project-spending claim.

Only if semantic exceeds lexical-syntax hunk coverage on at least two tasks at 2048 and vectors succeed will a separate live pilot be developed/frozen. It must validate defects/reference repairs, equal Sol-low budgets, independent acceptance and semantic tool activation, under shared 22 attempts/$3/100 MiB limits. Offline coverage never establishes capability. A failed gate ends usefully without live repair evidence.
