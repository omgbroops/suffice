Arms: A ordinary Luna-low; B Luna-low plus all three safeguards together; C ordinary Luna-xhigh with none of B's changes. A/C use the exact original issue prompt and system prompt. B appends the same generic instructions.txt for every task, adds source/probe observations and a deterministic public completion gate, and permits one repair continuation in the same session after gate failure. The gate restores ORIGINAL public test bytes in a separate public workspace and executes native tests and type/build commands independently, followed by the model-authored probe/preservation scripts. Its only task-specific inputs are public native commands, original public paths and pre-existing public native failure names/exit codes. Hidden graders, solutions, old actor patches, old actor traces and failure-taxonomy details are never given to workers. Added scripts must use public APIs and publicly supported assertions. Their validity will be reviewed separately; their passing is not acceptance.

The pre-edit probe must actually execute before any recorded production change and without changing production in its command. The wrapper compares exact public production hashes around tool execution and records candidate executions; a meaningful discriminating probe still requires source/output review. A missing or late pre-edit probe is nonactivation, not a success inferred from the instruction. After editing, code runs both authored checks. The gate may detect a bad authored test; repair feedback explicitly asks the worker to distinguish test errors from implementation errors using public contracts. Do not infer a coding improvement from detection alone.

The minimal system prompt, native primitives, codemode schema, navigation and append-only history remain identical.
