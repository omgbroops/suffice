# Luna baseline v1: exposed historical calibration

Prepared separately from the running Sol/native-Pi campaign. No inference may start until the parent agent confirms that the main comparative set is complete and authorizes launch. Preparation and zero-inference preflight are permitted. This is a model-only baseline, not the behavioral-evidence experiment in the research note.

Four tasks are declared before examining corrected main-campaign outcomes: s01 Emittery #118 (async meta-event behavior); i01 node-fetch #1386 (malformed redirect errors); q04 Nanostores #371 (state across module instances); i03 p-limit #110 (mapper/iterator rejection). These are exposed historical calibration tasks reused from the main campaign, not untouched holdout or fresh capacity evidence. No task replacement after observing Luna outcomes. q03 remains excluded for its unsupported cancellation contract. i04 is fastq mutable concurrency, not cancellation.

Only Suffice/Luna runs are scheduled: one attempt per task, serial in the listed order. The existing Sol Suffice results on matching valid contracts provide a descriptive stronger reference. There is no Astra execution or Astra-quality measurement, and no new stock-Pi run. Four observations cannot establish population accuracy or statistical superiority.

The 14 pinned general-v1 files are copied to `runtime-source/`; original and variant SHA-256 values and all substitutions are recorded in `source-manifest.json`. System prompt, native tools plus AST through codemode, low effort, retry settings, compaction/cache-warming policy, resource limits and event recording remain unchanged. No planner, reviewer, routing, retention, navigation or probe mechanism is added.
