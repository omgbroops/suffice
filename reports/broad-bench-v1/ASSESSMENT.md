# Assessment

The useful finding is a cost/quality frontier, not proof of a v2 routing improvement. Existing Suffice v1 on Sol Medium matches native Codex strict acceptance here while reducing recorded cost and actor runtime. Luna costs much less, with a modest drop in strict acceptance on this sample.

Keep the v2 additions experimental. On fully accounted same-model Luna pairs excluding the provider-interrupted issue, v2 ties acceptance and is slightly more expensive/slower. No advice, repair or takeover triggered, so this run cannot assess those mechanisms. The 15 issues do not justify a default switch or a claimed general accuracy improvement.

Any next calibration should use independent development tasks and a new frozen held-out cohort, with individual feature ablations. Preserve this campaign, all failures, the two unknown costs and the continuation amendment rather than using these 15 issues as both tuning data and proof.

The b02 grader extends the original issue with an unsupported bare-hash requirement. All arms pass the core LF JSON checks before failing that extra rule. Keep the frozen strict scores for provenance, but do not treat them as validated issue-resolution rates or silently rescore this campaign.
