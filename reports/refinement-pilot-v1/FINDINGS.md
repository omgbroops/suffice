# Recommendation after the 20-attempt pilot

Keep Flexible, Efficient and Orchestrated as separate experimental policies over
the shared core. Do not change the production default. The complete cohort cost
$1.2026944 API-equivalent, including planning, failed attempts and repairs, with
no unknown costs or ungraded attempts. No reruns replaced outcomes.

Pi and V1 each accepted 5/5; V2 and V3 each accepted 4/5. Compared with Pi, V1
cost 46.1% more and averaged 18.4% longer. V2 cost 83.3% less in total, or 79.1%
less per accepted task including its failure, and averaged 9.3% longer. V3 cost
30.4% less in total, or 13.0% less per accepted task, and averaged 112.3% longer.
These are observed five-task results, not accuracy or savings guarantees.

V3 demonstrates bounded Sol coordination and Luna implementation, but does not
improve acceptance here. Sol accounts for 84.6% of V3 cost. Eight sequential
delegations include two extra COBOL implementation rounds and one polyglot
investigation. Keep deterministic tool calls and direct output retrieval cheap;
do not add a paid Luna interception to every V1 tool call. Any later trial of
parallel workers needs isolated editing ownership rather than racing writes.

V2 issued five upfront Sol plans and one Sol takeover. Its takeover followed a
Luna repair that still failed the public check. Thus assistance is observable
and can activate; neither this run nor the earlier absent activation establishes
that assistance improves correctness. There is no unassisted Luna control here.

The most concrete next refinement is to separate verification prerequisites
from candidate behavior. The polyglot public check fails when system python3 is
missing, although the task's source can be exercised with the separately mounted
checker interpreter. Pi was independently accepted despite that public failure.
V1 paid $0.031034 for a repair triggered by the missing-interpreter diagnostic.
V2's repair and takeover left that same diagnostic unresolved; V3 also ended with
failed public verification. Both were independently rejected. The public
diagnostic alone does not establish the cause of either independent rejection;
no hidden evaluator contents were inspected to reverse-engineer them.

V3's investigation delegate also could not read the public checker because it
was outside the repository file tool's allowed scope. That read-only delegate
had no shell fallback, and reported the limitation accurately. Future scoped
evidence access should be explicit and bounded; another paid investigation
cannot solve a tool permission mismatch. Do not relax repository guards globally.

For the next implementation milestone, retain original-byte output recovery,
explicit verification evidence and task-scope guidance as independent opt-ins.
Classify missing prerequisites as unverified infrastructure evidence, preserve
the exact invocation environment, and request a model repair only for an observed
candidate failure. Use existing project checks plus a small issue-derived
reproducer. Do not infer full correctness from a smoke-test pass or silently
claim an actor's modified-PATH check equals the fixed controller command.

Prepared context, advisory notices and upfront planning still need separate
same-model, same-effort ablations on fresh tasks. This pilot bundled changes;
it cannot identify their individual contribution. No compaction treatment was
tested, and V3 coordinator input context peaked at 22,801 tokens. None of these
five tasks exercises Suffice's JavaScript/TypeScript AST navigation advantage.

All ten completed V2/V3 receipts reconcile non-overlapping stage costs with the
assistant-response ledger. Actual coordinator calls contain no general shell or
editing tools. All 51 frozen runtime inputs, 16 public inputs and five task
contracts were rechecked against the manifest. Original 120-slot reports and
production CLI source remain unchanged from 526eee4. The finite controller
finished with exit code zero and has no pending attempts.

Source is committed and pushed for the user's later pull on the Mohammed machine;
that offline machine has not been claimed synchronized. Full test-suite evidence
remains 153 passing and two documented pre-existing failures; see VALIDATION.md.
