# Interpretation boundaries

- These are the original ten exposed GitHub issues, one newly sampled actor session per harness and issue, not a fresh confirmatory holdout. Six repositories and mostly localized production changes do not represent the full long-horizon engineering distribution.
- Native Codex 0.163.0 is the actual CLI with native prompts, code execution, tools and compaction. Suffice keeps its frozen architecture with only effort changed to xhigh in a separate copy. Their instruction lengths, tool schemas, context handling and retry behavior differ by design. Both have the same original issue text and public policy.
- Native usage is deduplicated per response and checked against the final aggregate. Native logs do not expose every HTTP request in the same format as Suffice's request observer. Preserve transport errors and unpriced attempts; do not describe request counts as equivalent observations.
- Both actors use the same external mounts, dependencies, CPU affinity, memory observer and process limits. The larger virtual-address allowance is required for native Codex's runtime; original benchmark environments and baselines are unchanged. RSS sampling is approximate, and shared pages can be counted more than once.
- The first background attempt was interrupted when WSL terminated. It is preserved in v1, classified as operational, and separately included in inclusive cost bounds. Its missing in-flight usage prevents claiming a complete overall spend. A fresh namespace avoids mixing interrupted and valid task environments. This is an environment-based exclusion made before any matched-pair coding result, not removal of a failed implementation.
- Codex compatibility checks made two priced successful provider sessions before the scored runs; these can warm shared prompt prefixes. There was no paid Suffice warmup in this campaign. Counterbalanced task order does not erase that cache-history difference. Per-attempt cache tokens and component costs are reported.
- Both use ChatGPT-managed subscription access. The current credential formats did not expose comparable explicit account identifiers, so account equality is not independently established. No credential values are included in evidence exports.
- Actor tests are restored before independent grading. Passing the frozen checks is not proof of complete API correctness. Supplementary probes established by prior independent review are applied to both harnesses without actor feedback or changes to frozen scores. Native CI dependency omissions and previous timing instability remain relevant.
- Native model-visible tool calls, native command executions, and Suffice wrapper/primitive calls have different observability. They are reported separately rather than treated as interchangeable counts. Model responses and actor latency are the more comparable totals; latency still reflects contention when independent pairs overlap.
- API-equivalent costs price all recorded actor inference. They are not subscription cash charges and exclude the engineering parent's inference, machine time, power and infrastructure. Setup and interrupted attempts have a separate inclusive ledger.
