# Layered tenant routing
Repair createRouter({ defaults, routes }) exported by src/index.mjs. Each route is { id, pattern, settings }. resolve(tenant, path) returns a settings snapshot with route added, or null if no route matches. setTenant(tenant, overrides) replaces that tenant's overrides.

Paths and patterns are literal, case-sensitive strings. An exact pattern beats every wildcard. Wildcards are "*" or a prefix ending in "/*". A prefix matches its base path and descendants at a slash boundary: "/app/*" matches "/app" and "/app/x", not "/apple". Among matching prefixes choose the longest; declaration order only breaks equal specificity.
Settings merge in order: defaults, matched route settings, tenant overrides. Missing fields inherit. Explicit enabled=false, timeout=0 and label="" must survive. For headers, merge individual names; a header value of null deletes that inherited name. Other values, including empty strings, override. Header names in this exercise are already canonical lowercase.
Tenant overrides may be replaced repeatedly. Cached results must reflect the latest revision for the requested tenant and must never leak settings across tenants sharing a path. Each resolve result is a deep owned snapshot, and constructor/update inputs must not alias state.
Fields are enabled, timeout, label, target and headers. Unmentioned fields remain absent. Assume well-formed routes/settings, nonempty tenant names, and absolute paths; validation of malformed configuration is outside this exercise. Preserve public APIs and leave archived tooling functional.
