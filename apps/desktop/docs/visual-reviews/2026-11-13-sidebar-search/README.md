# Sidebar and Spotlight visual review

Local Electron screenshots from isolated test profiles at 1440 x 900. Fixtures use sample projects and transcripts.

- `sidebar-information-dark.png` and `sidebar-information-light.png`: detailed rows in both themes.
- `sidebar-hover-refined.png`: organized hover detail.
- `sidebar-compact.png`: one-line rows and quiet completed states.
- `sidebar-project-groups.png`: grouped chats, project identity, and repository totals.
- `sidebar-scroll-spacing.png`: full-width rows with the independent edge scrollbar.
- `spotlight-dark.png` and `spotlight-light.png`: the floating search surface without a dimmed or blurred backdrop.
- `none-composer-flat.png`: an archived experiment that was reverted; the current composer retains its drop shadow.

These capture design iterations rather than a pixel-perfect baseline for every final interaction. The automated Electron checks cover keyboard search, grouping, filters, persisted preferences, concurrent runs, steering, chat receipts, native hit targets, and cached navigation. Generated root-level screenshots remain ignored; review images are added here explicitly.
