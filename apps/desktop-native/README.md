# Native desktop viewer (experimental)

A read-only, native egui candidate. This is not the production desktop and is not a migration or a parity claim. It requires explicit `--home` and `--project` paths, intended for isolated synthetic fixtures only. It uses the experimental `suffice-session` crate for discovery and Pi projection; see that crate's README for its limitations. No user home is inferred, no provider is called, and no session is written.

Build with Rust 1.92: `cargo build --release --locked --manifest-path apps/desktop-native/Cargo.toml`. Run `apps/desktop-native/target/release/suffice-desktop-native.exe --home <fixture-home> --project <fixture-project>`. Sessions must be under `<home>/sessions/<directory>/*.jsonl`. `node apps/desktop-native/smoke.mjs` creates a temporary 1,000-message fixture, runs the release executable, checks JSON events and file hash, then removes the fixture. `--smoke --hold-seconds N` selects the named benchmark session programmatically and emits selection and shutdown events; these events report application state and completed egui layout, not OS-level presentation or interaction. `ready` currently means discovery complete, before window creation; it is not an equivalent desktop-ready measurement. The hold period allows process sampling but no comparable measurements are included here.

Session buttons and selectable CommonMark text render natively. Text supports Markdown and code blocks; other content blocks, including thinking and tool calls/results, are collapsed as formatted data. Scrolling supports egui scrolling, a follow option, and Jump to latest / Ctrl+End. Accessibility support is compiled in via eframe's AccessKit feature, but screen-reader and keyboard interaction have not been independently validated.

No composer/send, live stream, attachments or images, math, Mermaid, terminal, settings, project management, approvals, provider settings, syntax highlighting parity, or session mutation are implemented. This is not an SDK-backed chat client. Inter is not embedded; egui's default font and dark colors loosely follow the desktop design. Long transcripts are fully laid out rather than virtualized. The 64 MiB check happens after the session core's discovery has already read candidate files, so it is not a secure resource boundary; discovery also has documented symlink limitations. Do not use untrusted session roots or actual user data. The smoke test selects programmatically and checks data and layout, not actual mouse/keyboard behavior, visibility, accessibility, pixel parity, or performance. Markdown links may open an external browser when clicked.
