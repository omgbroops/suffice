# Native desktop viewer (experimental)

A read-only, native egui candidate. This is not the production desktop and is not a migration or a parity claim. It requires explicit `--home` and `--project` paths, intended for isolated synthetic fixtures only. It uses the experimental `suffice-session` crate for discovery and normalized saved desktop presentation and usage; see that crate's README for its limitations. No user home is inferred, no provider is called, and no session is written.

Build with Rust 1.92: `cargo build --release --locked --manifest-path apps/desktop-native/Cargo.toml`. Run `apps/desktop-native/target/release/suffice-desktop-native --home <fixture-home> --project <fixture-project>` on macOS/Linux, or add `.exe` on Windows. Sessions must be under `<home>/sessions/<directory>/*.jsonl`. `node apps/desktop-native/smoke.mjs` creates a temporary 1,000-message fixture, runs the release executable for the current platform, checks JSON events and file hash, then removes the fixture. `--smoke --hold-seconds N` selects the named benchmark session programmatically and emits discovery, first-UI-update (`ready`), selection and shutdown events; these events report application state and completed egui layout, not OS-level presentation or interaction. `ready` is emitted after the first eframe update has built the UI, but it is still not an equivalent desktop-ready measurement. The hold period allows process sampling but no comparable measurements are included here.

Session titles have case-insensitive search. While the search field has focus, Up/Down chooses a matching session and Enter opens it; session controls otherwise retain egui's standard focus/activation behavior. Selectable CommonMark text renders natively. Text supports Markdown and code blocks; persisted reasoning is suppressed like the production saved transcript, and tool calls use collapsed details. Saved attachment name, size and type metadata and compaction/interruption markers are shown; attachment paths are not presented. Saved usage displays unknown values as a dash. Scrolling supports egui scrolling, a follow option, and Jump to latest / Ctrl+End. Accessibility support is compiled in via eframe's AccessKit feature, but screen-reader and keyboard interaction have not been independently validated.

No composer/send, live stream, attachment opening or images, math, Mermaid, terminal, settings, project management, approvals, provider settings, syntax highlighting parity, or session mutation are implemented. This is not an SDK-backed chat client. Inter is not embedded; egui's default font and dark colors loosely follow the desktop design. Long transcripts are fully laid out rather than virtualized. Discovery and selection now use a retained `SessionStore` directory capability, reject symlink path components, and enforce the session crate's byte/line/catalog budgets during reads. Oversized or invalid candidate histories are reported in the viewer. These input budgets do not bound decoded projection/layout RSS or regular-file I/O latency, and Windows/Linux capability behavior remains unqualified. Do not use untrusted session roots or actual user data. The smoke test selects programmatically and checks data and layout, not actual mouse/keyboard behavior, visibility, accessibility, pixel parity, or performance. Markdown links may open an external browser when clicked.
